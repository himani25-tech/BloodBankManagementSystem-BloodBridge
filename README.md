#BloodBankManagementSystem-BloodBridge

##📖 Overview

The Blood Bank Management System replaces slow, error-prone paper registers with a centralized digital platform. Donors can register in seconds, hospitals can check blood availability in real time, and administrators get a live dashboard of stock, requests, and donor data — all backed by a secure, structured database.

##Features

Donor Registration - Simple, validated online form to register new donors
Real-Time Blood Search - Instantly check stock availability by blood group
Request Management - Hospitals/patients submit requests; admins approve or reject
Centralized Database - Single source of truth for donors, stock, and requests
Admin Dashboard - At-a-glance view of stock levels, donors, and pending requests
